# Radar Tower *(unofficial title; `army1`)*

*An unreleased mission of Urban Chaos. Back to [the story overview](../STORY.md).*

`levels\army1.ucm`, map `army1.iam`

**Played as:** Darci

**Story:** A prototype on an army base with a map of its own (`army1.iam`): sabotage the radar tower. Switches unlock lifts and open a gate, and workmen checking the air conditioning say the base is 'nuke proof'. Wildcats with pistols stand guard, among twenty guards the file gives the hostage type, with mines and barrels about. It's won once the system is sabotaged.
